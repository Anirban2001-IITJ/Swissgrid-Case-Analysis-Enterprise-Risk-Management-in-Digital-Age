# Swissgrid-Case-Analysis-Enterprise-Risk-Management-in-Digital-Age

- Analyzed a utility’s strategic shift to a decentralized Enterprise Risk Management (ERM) framework.
- Built a risk heat map prioritizing enterprise threats to drive disciplined capital allocation and operational resilience.
- ##The Data-Driven Solution: Optimized their models to heavily penalize False Negatives (ensuring public safety and grid stability) while using secondary, AI-driven filtering layers to automatically resolve harmless False Positives before they reach human operators.
